Reglas de Enrutamiento
  • Score 80–100: Cliente Ideal

    Redirigir directamente al calendario de agendamiento.

  • Score 60–79: Fit Medio / Potencial

    Evaluar internamente el stack técnico antes de confirmar la llamada.

  • Score < 60: No Vender

    Descartar para el sistema actual. Enviar a contenido educativo / base de conocimientos.
